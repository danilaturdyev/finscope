# FinScope

Сайт-помощник по акциям США «понятным языком». Страница одна (`index.html`), данные каждой акции лежат отдельным файлом.

## Структура
- `index.html` — шаблон сайта (вёрстка, графики, перевод RU/EN). Данных акций в нём нет.
- `data/stocks.json` — список акций (тикер, название, подпись для поиска, логотип, альтернативные названия).
- `data/<ТИКЕР>.json` — все данные одной акции: цены (`daily`), вердикт (`verdict`), бегущая строка (`tape`), плашки (`pills`), вкладки (`tabs`).
- `data/logos/<ТИКЕР>.png` — логотип (необязательно, без него показывается буква).
- `worker/worker.js` — Cloudflare Worker: отдаёт сайт из GitHub и живые цены `/api/series?r=0|1|2&t=ТИКЕР` (Twelve Data, ключ в секрете `TD_KEY`). Разрешены только тикеры из `data/stocks.json`.
- `tools/validate.mjs` — проверка данных: `node tools/validate.mjs`. Запускать перед каждым коммитом.

## Как добавить акцию
1. Подготовьте `prices.csv` с дневными ценами (`ГГГГ-ММ-ДД,open,high,low,close,объём_млн`, по возрастанию).
2. `node tools/new_stock.mjs ТИКЕР "Название" "Юр. название" "Биржа" "Отрасль RU" "Отрасль EN" prices.csv [--round] [--mic XNYS]` создаёт заготовку `data/<ТИКЕР>.json` со всеми 11 вкладками и запись в `data/stocks.json`. Везде стоит метка `TODO`: пока она есть, `validate` не пропустит акцию.
3. Положите логотип `data/logos/<ТИКЕР>.png` и допишите `"logo":"logos/<ТИКЕР>.png"` в `stocks.json`. Заполните все `TODO` и поле `en` (переводы).
4. `node tools/build_quotes.mjs` (карточки на главной), `node tools/og.mjs <ТИКЕР>` (картинка для ссылок), `node tools/validate.mjs`. Закоммитьте и отправьте в `main`.
5. Адрес акции: `/ТИКЕР` (воркер отдаёт страницу с описанием для поисковиков), в приложении `/#/ТИКЕР`. Новый тикер попадает в `/sitemap.xml` автоматически.

Поле `sector` в `stocks.json` (например «Энергетика») нужно главной странице для фильтров; перевод кладите в `en` этой записи.

## Формат `data/<ТИКЕР>.json`
Обязательные поля: `t`, `name`, `asof` (дата последней сессии), `daily` (`[дата, open, high, low, close, объём млн]`, даты по возрастанию), `verdict` (`title`, `text`, `pil` — список `[название, 1..5, подпись]`), `tape`, `tabs`.

Необязательное поле `events` — ближайшие события для блока «Ближайшие события» на странице акции: `[{"d":"2026-11-03","t":"Квартальный отчёт…","s":"пояснение","est":1}]`. `est:1` — дата ожидаемая, не подтверждённая компанией. Прошедшие даты скрываются сами; тексты `t` и `s` нужно добавить в словарь `en`. Обновляйте даты после каждого отчёта.
Необязательные: `sub`, `legal`, `logo`, `logoShape` (`round` для круглого логотипа), `td` (`{symbol, mic}` для источника цен, например `XNYS`), `en`, `ext` (пре/пост-маркет последней сессии), `sparse` (редкие старые точки), `note` (пометки к датам), `pills`, `histnote`, `updated`, `reviewed` (дата последнего полного разбора текстов, показывается на странице как «Разбор обновлён…»; быстрое ежедневное обновление её не меняет, еженедельное ставит сегодняшнюю).

`tabs` — список `{k, name, blocks}`. Блок — это `{card:{h, parts}}`, `{g2:[card,card]}`, `{d:"текст"}` или `{scenarios:{...}}` (калькулятор, не более одного на акцию). Части карточки (`parts`), по одному типу на элемент:
`p`, `d` (серый текст, можно `style`), `cn` (мелкая сноска), `cnlink` `[текст, ссылка]`, `kv` `[[подпись, значение, класс]]`, `items` `[[g|r|y, заголовок, текст]]`, `tt` `[[подпись, значение, класс]]`, `bar` `[[доля, ok|mid|bad]]`, `rbs` (диапазоны цены, `min`/`max` шкалы), `tl` `[[когда, текст]]`, `chart` `{items:[{l,v,ap}], label, pos, neg, h}`, `files`, `news`, `src`, `gloss`.
Классы значений: `pos`, `neg`, `mid`, `up`, `dn`.

Каждая новая русская фраза, видимая на странице, должна иметь перевод. Переводы лежат в поле `en` самого файла акции (`{"русская фраза":"English phrase"}`), общие фразы сайта в `EN_PAIRS` внутри `index.html`. В английском тексте не ставьте запятую между цифрами (пишите `1 387`, а не `1,387`).

Финансовая информация носит справочный характер и не является инвестиционной рекомендацией.

## Дополнительно

- Превью для ссылок: `node tools/og.mjs [ТИКЕР]` создаёт `data/og/<ТИКЕР>.png` (1200x630). Для новой акции запустите и закоммитьте картинку. Воркер отдаёт страницу `/s/<ТИКЕР>` с этим превью, кнопка «Поделиться» ведёт на неё.
- Подсказки терминов берутся из вкладки «Словарь» (`gl`) самой акции: латинские термины из названий словарных статей подчёркиваются в тексте.
- Счётчик просмотров: воркер считает открытия страниц по дням в KV (привязка `STATS`), страница `/stats?key=<STATS_KEY>`. Без привязки счётчик просто выключен.
- Праздники биржи для значка рынка лежат в `index.html` (`HOL`, `EARLY`), сейчас на 2026–2027 годы. Обновляйте их раз в год по https://www.nyse.com/markets/hours-calendars.

## Обновление данных
- `trig_…` «быстрое ежедневное обновление цен» (каждый день 07:27 по Лондону): цены, `asof`, плашки, строки «Котировка»; помечает акции, которым нужен полный разбор.
- «полное еженедельное обновление разбора» (воскресенье 09:43 по Лондону): новости, вердикт, опционы, SEC, отчётность, сценарии.
- Обе задачи запускают `node tools/build_quotes.mjs` и `node tools/validate.mjs`. `data/quotes.json` (цена и вчерашнее закрытие для карточек главной) собирается из файлов акций и проверяется валидатором.

## Автодеплой воркера
`wrangler.jsonc` в корне: подключите репозиторий в Cloudflare (finscope -> Settings -> Builds -> Connect), команда деплоя `npx wrangler deploy`. После этого каждый коммит в `main` сам обновляет `worker/worker.js`. Привязки (AI, KV STATS) должны быть описаны в `wrangler.jsonc`, иначе деплой их уберёт.

## Страницы сайта
`/#/about` (О нас), `/#/legal` (Отказ от ответственности и источники), `/ТИКЕР` (акция), `/sitemap.xml`, `/robots.txt`. Основной адрес сайта: https://finscope.uk (константа `SITE` в `worker/worker.js`), `www` перенаправляется на него.

## Главная при большом числе акций
- Если акций 6 и больше, главная показывает ряды «Растут сегодня» и «Падают сегодня» (топ-5, с мини-графиком), строку секторов (3 крупнейших и «Ещё ▾») и кнопку «Все акции». Выбор сектора открывает список его акций. Если акций меньше 6, показывается один список, как раньше.
- Мини-графики берутся из `data/quotes.json` (поле `s` — последние 20 закрытий), файл собирается `node tools/build_quotes.mjs`.

## Новости на главной (data/news.json)

Баннер-карусель справа в шапке главной показывает экономические новости. Формат: `{"updated":"ГГГГ-ММ-ДД","items":[{"k":"fed","t":"Заголовок","s":"Описание в 1–2 предложения своими словами","src":"Издание","u":"https://ссылка","d":"ГГГГ-ММ-ДД","en":{"t":"Title","s":"Summary"}}]}`. Тема `k` задаёт цвет и значок: fed, cpi, imf, cn, ai, mkt, eu (для остальных берётся fed). Нужно от 3 до 10 новостей. Пересказывать своими словами, не копировать текст статьи; ссылка должна вести на реально открытую страницу. Файл обновляет ежедневная задача.

## Компании без разбора и запрос разбора по кнопке
- Поиск на сайте работает по всем акциям американских бирж: воркер `/api/universe` раз в сутки забирает список SEC (запасной источник Nasdaq Trader), убирает ETF и кэширует в KV (`uni:v2`).
- Для компании без разбора страница `#/ТИКЕР` показывает живую цену и график (`/api/series`, разрешены тикеры из этого списка) и кнопку «Запросить разбор».
- Кнопка вызывает `POST /api/request?t=ТИКЕР`. Воркер проверяет тикер, гасит дубли (KV `req:ТИКЕР`, 4 часа), считает дневной лимит (`REQ_DAILY`, по умолчанию 10) и запускает задачу «FinScope: новый разбор» через её API (секрет `ROUTINE_TOKEN`, переменная `ROUTINE_ID`). В задачу уходит строка `NEW:ТИКЕР|Название|MIC`.
- Задача собирает `data/<ТИКЕР>.json` и запись в `data/stocks.json` по этому README и пушит в main. Страница на сайте открывается сама, когда тикер появляется в реестре.

## Лидеры рынка на главной
Виджет «Рынок сегодня» показывает 5 самых растущих и 5 самых падающих американских акций. Источник: воркер `/api/movers` берёт общий список акций Nasdaq (api.nasdaq.com), фильтрует (капитализация от 2 млрд $, цена от 5 $, объём от 500 тыс., без фондов, варрантов, прав и привилегированных) и кэширует: 10 минут во время сессии (данные с задержкой до 15 минут), 3 часа в остальное время. Если источник недоступен, сайт берёт запасной файл `data/movers.json` (формат: `{"asof":"ГГГГ-ММ-ДД","updated":"ГГГГ-ММ-ДД","up":[{"t":"APP","name":"AppLovin","p":541.45,"c":8.4}],"dn":[...]}`, его может обновлять ежедневная задача), а если нет и его, показывает прежние ряды по акциям с разбором. Проверка работы: открыть `/api/movers`, при сбое в ответе будет поле `why`.

## Цены скриптом (GitHub Actions)
`.github/workflows/prices.yml` по будням в 21:30 UTC запускает `tools/update_prices.mjs`: дописывает дневные свечи, правит закрытие и дневной диапазон, пересобирает `quotes.json`. Нужен секрет репозитория `TD_KEY` (Settings → Secrets and variables → Actions). Тексты разбора скрипт не трогает.

## Telegram-бот
Код в `worker/worker.js` (раздел «Telegram-бот»). Нужен секрет Cloudflare `TG_TOKEN` (токен от @BotFather). После деплоя один раз открыть `https://finscope.uk/api/tg?setup=1&key=<STATS_KEY>`, затем написать боту `/start`. Бот личный: подписчик — первый, кто написал `/start`. Оповещения идут по расписанию (cron в `wrangler.jsonc`) из `data/quotes.json`: движение за день больше порога и «завтра/сегодня отчёт». Команды: /list, /watch, /unwatch, /threshold, /test, /stop.
